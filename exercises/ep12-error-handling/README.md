# แบบฝึกหัดตอนที่ 12 — error handling (Result)

## โจทย์
เขียนฟังก์ชัน `divide` ให้คืนค่า `Result<i32, String>` — ถ้า `b == 0` คืน `Err` ไม่งั้นคืน `Ok(a / b)`

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วยโค้ดที่ตรวจ `b == 0` แล้วคืน `Err(...)` / `Ok(a / b)`
3. รัน `cargo test` — ต้องผ่านทั้ง 3 เทส

## แนวคิดที่ได้ฝึก
- `Result` = ประสบความสำเร็จ (`Ok`) หรือผิดพลาด (`Err`) — ไม่ panic ตอนหารศูนย์

## ตารางตรวจคำตอบ
| a  | b | ผลลัพธ์      |
|----|---|--------------|
| 10 | 2 | Ok(5)        |
| -6 | 3 | Ok(-2)       |
| 5  | 0 | Err (is_err) |
