# แบบฝึกหัดตอนที่ 11 — modules

## โจทย์
เติมฟังก์ชัน `square` ภายใน module `math` ให้คืนค่า x ยกกำลังสอง

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วยโค้ดที่คืนค่า `x * x`
3. รัน `cargo test` — ต้องผ่านทั้ง 2 เทส

## แนวคิดที่ได้ฝึก
- เรียกใช้ฟังก์ชันใน module ด้วย `math::square(...)`

## ตารางตรวจคำตอบ
| x  | ผลลัพธ์ |
|----|---------|
| 4  | 16      |
| -3 | 9       |
