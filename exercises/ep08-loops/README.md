# แบบฝึกหัดตอนที่ 8 — ลูป (loop / while / for)

## โจทย์
เขียนฟังก์ชัน `sum_to` คืนค่าผลรวม `1 + 2 + ... + n` โดยใช้ `for`

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วย `for` วนบวกเลข `1..=n`
3. รัน `cargo test` — ต้องผ่านทั้ง 3 เทส

## ตารางตรวจคำตอบ
| n | ผลรวม |
|---|-------|
| 5 | 15    |
| 1 | 1     |
| 0 | 0     |
