# แบบฝึกหัดตอนที่ 17 — done / edit / delete

## โจทย์
เขียนฟังก์ชัน `mark_done` ให้หางานที่ `title` ตรงกัน แล้วตั้ง `done = true` (คืน `true`); ถ้าไม่เจอให้คืน `false`

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วย `for` วนหา + ตรวจ `title` แล้ว set `done`
3. รัน `cargo test` — ต้องผ่านทั้ง 2 เทส

## แนวคิดที่ได้ฝึก
- `iter_mut()` = วนลูปที่แก้ไขค่าข้างในได้
- คืน `bool` บอกว่าเจอ/ไม่เจอ (ใช้ตรวจ error ได้)

## ตารางตรวจคำตอบ
| mark_done(..., "ซื้อของ") | ผลลัพธ์ |
|---------------------------|---------|
| มีงาน "ซื้อของ" | true + done=true |
| ไม่มีงานชื่อนั้น | false |
