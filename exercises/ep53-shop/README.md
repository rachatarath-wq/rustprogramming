# แบบฝึกหัดตอนที่ 53 — ร้านค้า

## โจทย์
เขียนฟังก์ชัน `buy` — ถ้าเหรียญพอซื้อ (`coins >= price`) ให้หักแล้วคืนยอดใหม่เป็น `Some`; ถ้าไม่พอคืน `None`

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วย `if coins >= price { Some(coins - price) } else { None }`
3. รัน `cargo test` — ต้องผ่านทั้ง 3 เทส

## แนวคิดที่ได้ฝึก
- `Option<i64>` = "มีผลลัพธ์" (Some) หรือ "ไม่มี/ไม่สำเร็จ" (None)
- กันไม่ให้ยอดเหรียญติดลบ (กฎของร้านค้าจริง)
