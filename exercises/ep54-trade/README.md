# แบบฝึกหัดตอนที่ 54 — เทรดเหรียญ

## โจทย์
เขียนฟังก์ชัน `transfer` โอนเหรียญจาก `sender` ไป `receiver` — ถ้า `sender` มีพอคืน `Ok((ยอดใหม่ sender, ยอดใหม่ receiver))`; ถ้าไม่พอคืน `Err`

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วย `if sender >= amount { Ok((sender - amount, receiver + amount)) } else { Err("เหรียญไม่พอ".to_string()) }`
3. รัน `cargo test` — ต้องผ่านทั้ง 3 เทส

## แนวคิดที่ได้ฝึก
- `Result<(i64, i64), String>` = สำเร็จคืน 2 ค่า (ยอดทั้งคู่) / ผิดพลาดคืน Err
- การโอนต้องตรวจก่อนว่าพอ (ไม่ให้ติดลบ)

## ตารางตรวจคำตอบ
| sender | receiver | amount | ผลลัพธ์       |
|--------|----------|--------|---------------|
| 10     | 0        | 3      | Ok((7, 3))    |
| 2      | 0        | 5      | Err           |
| 5      | 2        | 5      | Ok((0, 7))    |
