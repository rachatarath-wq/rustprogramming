# แบบฝึกหัดตอนที่ 5 — Borrowing และ References

## โจทย์
เขียนฟังก์ชัน `word_count` ให้คืนค่าจำนวนคำในข้อความ (คั่นด้วยช่องว่าง) โดยรับ `&str` (ยืมมา ไม่ย้าย ownership)

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วยโค้ดที่ใช้ `s.split_whitespace().count()`
3. รัน `cargo test` — ต้องผ่านทั้ง 3 เทส

## แนวคิดที่ได้ฝึก
- พารามิเตอร์ `&str` = ยืมมาใช้ชั่วคราว ตัวแปรเดิมยังใช้ต่อได้
- ไม่ต้อง `clone` หรือย้าย ownership
