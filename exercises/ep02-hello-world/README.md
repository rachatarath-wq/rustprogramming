# แบบฝึกหัดตอนที่ 2 — โปรแกรมแรก (ฟังก์ชัน)

## โจทย์
เขียนฟังก์ชัน `greeting` ให้คืนค่าคำทักทาย `"Hello, {ชื่อ}!"`

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วย `format!("Hello, {}!", name)`
3. รัน `cargo test` — ต้องผ่านทั้ง 2 เทส

## แนวคิดที่ได้ฝึก
- `format!` = สร้างสตริงจากแม่แบบ (เหมือน `println!` แต่คืนค่าเป็น String แทนการพิมพ์)

## ตารางตรวจคำตอบ
| input    | ผลลัพธ์          |
|----------|------------------|
| "Rust"   | "Hello, Rust!"   |
| ""       | "Hello, !"       |
