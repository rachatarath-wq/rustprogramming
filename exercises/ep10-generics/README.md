# แบบฝึกหัดตอนที่ 10 — generics + trait

## โจทย์
เขียนฟังก์ชัน `largest` แบบ generic ให้คืนค่าที่มากกว่าระหว่าง `a` กับ `b` (ใช้ได้กับทั้งตัวเลขและสตริง)

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วยโค้ดที่ใช้ `if a > b`
3. รัน `cargo test` — ต้องผ่านทั้ง 2 เทส

## แนวคิดที่ได้ฝึก
- `T: PartialOrd` = type ที่เปรียบเทียบได้ด้วย `>` (มีทั้ง i32 และ &str)

## ตารางตรวจคำตอบ
| a     | b     | ผลลัพธ์ |
|-------|-------|---------|
| 3     | 7     | 7       |
| "a"   | "z"   | "z"     |
