# แบบฝึกหัดตอนที่ 26 — บันทึก / โหลดโลก

## โจทย์
แปลงโลก (`Vec<Block>`) เป็นข้อความที่บันทึกได้ (`save_world`) และอ่านกลับ (`load_world`)

## ขั้นตอน
1. เปิด `src/lib.rs`
2. `save_world`: ใช้ `map` + `format!("{},{},{},{}", ...)` แล้ว `join("\n")`
3. `load_world`: ใช้ `s.lines()` + `split(',')` + `.parse()`
4. รัน `cargo test` — ต้องผ่านทั้ง 2 เทส

## แนวคิดที่ได้ฝึก
- การ serialize (struct → ข้อความ) และ deserialize (ข้อความ → struct) แบบเขียนเอง
- `parse::<i32>()` แปลงสตริงเป็นตัวเลข

## ตารางตรวจคำตอบ
| ทำงาน | ผลลัพธ์ |
|-------|---------|
| save → load | ได้ Vec<Block> เดิมกลับมา |
| load("") | [] (empty) |
