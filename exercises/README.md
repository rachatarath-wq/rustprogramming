# แบบฝึกหัด (Exercises) — เรียนเขียนโปรแกรมภาษา Rust

แบบฝึกหัดลงมือเขียนจริง ใช้คู่กับคลิปวิดีโอแต่ละตอน

## วิธีทำ (3 ขั้น)
1. ติดตั้ง Rust ก่อน (ดูคลิปตอนที่ 2) แล้วโคลน repo นี้
2. เข้าโฟลเดอร์แบบฝึกหัดของตอนนั้น แล้วเปิด `src/lib.rs`
   ```
   cd exercises/ep03-variables
   ```
3. เขียนโค้ดแทนที่ `todo!()` ตามโจทย์ แล้วรันเทสตรวจคำตอบ
   ```
   cargo test
   ```
   - เขียว `test passed` = ถูกต้อง ✅
   - แดง `FAILED` = ยังไม่ถูก ลองแก้ใหม่

## โครงสร้าง
แต่ละโฟลเดอร์ = 1 บทเรียน ประกอบด้วย
- `src/lib.rs` — โจทย์ (ฟังก์ชันให้เติม) + เทสอัตโนมัติ
- `README.md` — คำอธิบายโจทย์ + ขั้นตอน
