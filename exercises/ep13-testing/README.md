# แบบฝึกหัดตอนที่ 13 — การเขียน test

## โจทย์
ฟังก์ชัน `add` ถูกเขียนไว้แล้ว — หน้าที่ของคุณคือเขียน **test** ให้ครอบคลุม

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ในแต่ละ `#[test]` ด้วย `assert_eq!(...)`
3. รัน `cargo test` — ต้องผ่านทั้ง 2 เทส

## แนวคิดที่ได้ฝึก
- `assert_eq!(จริง, คาดหวัง)` = ตรวจว่าค่าจริงเท่ากับค่าที่คาดหวัง
- test ชื่อสื่อความหมาย (`test_add_positive`, `test_add_negative`)

## ตารางตรวจคำตอบ
| add(...)   | คาดหวัง |
|------------|---------|
| add(2, 3)  | 5       |
| add(-1, 1) | 0       |
