# แบบฝึกหัดตอนที่ 4 — Ownership

## โจทย์
เขียนฟังก์ชัน `append_world` ให้รับ `String` เข้ามา (ย้าย ownership เข้ามาในฟังก์ชัน) แล้วเติมคำว่า `" world"` ต่อท้าย และคืนค่ากลับ

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วยโค้ดที่ใช้ `s.push_str(" world")` แล้วคืนค่า `s`
3. รัน `cargo test` — ต้องผ่านทั้ง 2 เทส

## แนวคิดที่ได้ฝึก
- พารามิเตอร์แบบ `String` (ไม่ใช่ `&String`) = ฟังก์ชัน "ยึด ownership"
- `mut` จำเป็นถ้าจะแก้ไขค่าของ `s`

## ตารางตรวจคำตอบ
| input   | ผลลัพธ์ที่ควรได้ |
|---------|-----------------|
| "hello" | "hello world"   |
| ""      | " world"        |
