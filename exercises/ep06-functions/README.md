# แบบฝึกหัดตอนที่ 6 — ฟังก์ชัน

## โจทย์
เขียนฟังก์ชัน `is_even` ให้คืนค่า `true` ถ้าเลขเป็นเลขคู่ และ `false` ถ้าเป็นเลขคี่

## ขั้นตอน
1. เปิด `src/lib.rs`
2. แทนที่ `todo!()` ด้วยโค้ดที่คืนค่า `n % 2 == 0`
3. รัน `cargo test` — ต้องผ่านทั้ง 3 เทส

## ตารางตรวจคำตอบ
| input | ผลลัพธ์ |
|-------|---------|
| 4     | true    |
| 7     | false   |
| 0     | true    |
